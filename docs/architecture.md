# Architecture and research traceability

Seven small modules form one local package. `data.py` is the trust boundary for CSV and market-data provenance. `broker.py` wraps only the official SDK account read class and reuses the CSV validation/accounting boundary. `models.py` supplies risk statistics, BL, covariance and scenarios. `optimize.py` owns convex allocation, residual checks, preview and explicit policy. `evaluation.py` runs frozen walk-forward experiments. `cli.py` orchestrates analysis, fixtures and escaped JSON/HTML reports; `__init__.py` marks the package. No background jobs, network calls or execution endpoint are part of offline analysis.

| Component / function | Research basis | Adaptation and unverified assumptions | Validation |
|---|---|---|---|
| `models.black_litterman`, `market_prior` | BL92, IDZ | Gaussian update by linear solve; supplied zero prior is not equilibrium. Dated external views and Omega required. Predictive covariance is innovation plus mean uncertainty. | PyPortfolioOpt mean/covariance reference; no-view test; PSD/Omega rejection |
| `models.covariance` | LW-I; LW-H distinction | sklearn scaled-identity Ledoit–Wolf default; sample/EWMA comparators. Covariance input finite/PSD checks. | PSD and seeded fixtures; OOS covariance error in evaluator |
| `models.empirical_es`, `optimize.optimize` | RU00; PK18 context only | Fractional empirical tail mass; convex scenario LP with linear net losses. Not asserted equivalent to elliptical closed form. | Independent SciPy LP and fractional/sign tests |
| `models.stationary_indices`, `scenarios` | PR94 | Synchronized centered residuals shifted to BL mean; bootstrap does not exactly impose shrinkage covariance. Gaussian predictive mode adds mean uncertainty once. Blocks do not improve one-day marginal information. | Pinned reproducibility; invalid simple returns; cross-family reported sensitivity |
| `optimize.optimize`, `residuals` | LFB07 | Proportional self-financing costs; normalized bounds remain affine; cash allowed. Actual costs, solver optimal status and residuals checked independently. | Randomized constraint cases; nonzero costs; infeasibility; repeated boundary rebalances |
| `optimize.preview_shares` | LFB07 motivates nonconvex distinction | Floor-round preview, no integer optimum, fixed fees/taxes omitted. Reconcile cash and recheck constraints or fail. | Cash reconciliation and rounded bound violation test |
| `cli.analyze`, `optimize.decide` | DN90 motivation; project policy | Fixed daily rounded-portfolio utility threshold; proposal hash binds external attestation to exact inputs/config. Observed investable data and verified attributed sessions required. Computed sensitivity failure or max L1 weight difference >.25 blocks action; this threshold is an uncalibrated engineering screen, not a continuous-time optimal no-trade boundary. | HOLD/REBALANCE/NO_TRADE, unchanged rounded quantities, evidence hash mismatch, synthetic/proxy/session gates, sensitivity failure/span, insufficient tails, violated-current constraints |
| `evaluation.evaluate`, `_erc` | DGU09; PR94; BBLZ caveats | Hypothetical common initial allocation; costs at transitions, drift; SLSQP equal risk contributions only if residuals pass. Paired block intervals conditional on stationarity. No PBO claim. | Strict train/test dates, costs, daily drift/cost-aligned tail forecasts, nonzero cash-rate total/excess consistency, strategy coverage, visible failures; coordinator-owned observed proxy experiment |
| `models.risk_metrics` | Standard return accounting; C98 limits | One-day ES/volatility, 252-day moment scaling, buy-and-hold drawdown; supplied factors OLS, no invented factors. Coverage is a diagnostic, not an independence test. | Drawdown initial wealth, date alignment and horizons |
| `data.read_portfolio`, `validate_returns` | Engineering trust boundaries | USD, daily adjusted total returns, explicit timestamps/provenance. Four-day age and six zero-return screening are engineering defaults. Permission declarations not independently audited. | Raw duplicate CSV headers, exact attributed session grids, sparse-date screen, schema, units, stale/negative cash, NAV, broker schema failures |
| `broker.read_webull` | Official SDK/docs | TH account eligibility and quote valuation freshness explicitly supplied; supported CASH accounts only. No order surfaces imported. | Read-only mocks, auth/connectivity/pagination rejection; live untested |

The coordinator owns `docs/research/*`, observed proxy preparation and empirical report interpretation. User account data/history were not supplied. Frozen research choices must not be tuned to favorable test results. Reports retain inconclusive and negative results. Unit tests and synthetic runs provide no evidence of investable superiority.

Analysis reports retain continuous diagnostics separately from rounded implementation accounting. The static HTML uses escaped composition/risk tables and a shared-bin inline SVG net-loss histogram; full JSON is expandable. Histogram counts, HTML escaping, rounded accounting, proposal binding, sensitivity gates and daily forecast units have regression tests.
